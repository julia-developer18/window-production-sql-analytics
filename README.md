Аналитический кейс по межсистемной интеграции данных, расчету себестоимости, маржинальности и материальных ведомостей из САПР «IT-Окна» для контура «1С:Управление производственным предприятием» (1С:УПП).

---

## 📌 Архитектурный контекст и бизнес-задача

На производственном предприятии использовались две изолированные системы:
1. **САПР «IT-Окна»** — инженерный расчет конструкций, расчет раскроя, списание сырья и спецификации изделий (BOM).
2. **ERP «1C:Управление производственным предприятием» (1С:УПП)** — финансовый учет, склад, продажи и себестоимость.

### Проблема:
В 1С:УПП регистрировался общий заказ, но отсутствовала оперативная детализация по фактически списанным комплектующим и сырьевой себестоимости каждого окна, так как эти данные оставались внутри базы САПР. Финансово-экономический отдел не мог оперативно сопоставить плановую и фактическую себестоимость.

### Решение:
Спроектированы аналитические SQL-запросы к базе данных «IT-Окна» для построения сквозных отчетов в контуре 1С:УПП:
* Извлечение состава конструкций и расхода материалов по заказам.
* Синхронизация себестоимости компонентов для расчета чистой валовой и операционной прибыли.
* Формирование отчетности: «Ведомость по товарам на складах», «Фактическая себестоимость и маржинальность заказов».

## 🗄 Структура таблиц базы данных

```text
[ spr_mat ] (Справочник сырья)
     │ 
     │ 1:N (id_mat)
     ▼
[ doc_acc_cnt_detals ] (Спецификация / BOM деталей)
     ▲
     │ N:1 (id_doc, id_str)
     │
[ doc_acc_cnt ] (Готовые конструкции в заказах)
```

| Таблица | Назначение | Ключевые поля |
| :--- | :--- | :--- |
| **`doc_acc_cnt`** | Изделия заказа (окна, двери, витражи), их габариты ($W, H$), площадь и отпускные цены | `id_doc` + `id_str` (PK), `f_sqrt`, `syma`, `calc_error` |
| **`doc_acc_cnt_detals`** | Поэлементный состав окна (профиль, стеклопакет, уплотнители) | `id_doc` + `id_str` + `id_detal` (PK), `kol`, `syma_seb` |
| **`spr_mat`** | Нормативно-справочная информация (НСИ) сырья и артикулов | `id_mat` (PK), `name`, `art`, `h_prof`, `prc_waste` |

## 📊 Ключевые реализованные SQL-решения

В файле [`/sql/analytical_queries.sql`](./sql/analytical_queries.sql) реализованы запросы:
* **Расчет валовой прибыли:** `(Selling_Price - SUM(syma_seb))` с группировкой по конструкции.
* **Аудит технологических ошибок:** Выявление позиций с `calc_error <> 0` до передачи заказа в цех.
* **Антифрод и аудит цен:** Выборка изделий, где цена или состав были изменены вручную (`zena_is_manual = 1`).
* **Логистический расчет:** Суммирование массы комплектующих по заказу (`SUM(massa)`).
* **Сводная ведомость сырья:** Группировка расхода материалов по группам номенклатуры для отдела снабжения.
